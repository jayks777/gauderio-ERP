# O sistema Gauderio-ERP deve coportar as seguintes funcionalidades:

- Cadastro de Receitas;
- Cadastro de despesas;
- Cadastro de despesas e receitas recorrentes;
- Cadastro de despesas (boletos) e receitas(vendas) futuras;
- Gráficos e relatórios para análise financeira;
- Interface bonita, suave e responsiva, com alguns detalhes nas cores da bandeira do Rio Grande do Sul;
- Entrada e saida de saldo;
- Controle das contas do banco;
- Central de boletos a receber e a pagar;

Obs: tudo isso deve ficar salvo em um banco de dados SQLIte ou JSON para visualizações futuras
